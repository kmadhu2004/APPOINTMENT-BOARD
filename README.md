# Appointment Board

An Appointment Board application that was developed using HTML, CSS and JavaScript. I can add, manage, update, complete, cancel and filter appointments with this app.

# Features

You can do the following using the Appointment Board:
- View all appointments
- Add appointments
- Update appointments
- Complete appointments
- Cancel appointments
- Filter appointments by date
- Filter appointments by status
- Clear all filters
- View appointment statistics
- Make sure all the fields are filled in correctly in an appointment
- Make sure that the end time is after the start time in an appointment
- Avoid overlaps in the schedule when an appointment is added
- Avoid overlaps in the schedule when an appointment is updated
- Keep cancelled appointments in the list as cancelled

# Technologies Used
In this project I used the following technologies and tools:
- HTML5
- CSS3
- JavaScript
- Local Storage
